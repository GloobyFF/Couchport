## 2026-10-20 fix: crash after entering the pairing PIN
- Cause: SIGPIPE (signal 13). The console closed the TCP connection during registration and the next send() killed the process.
- Fix: `signal(SIGPIPE, SIG_IGN)` in `PS5VisionCaptureApp.init()`, `RemotePlayLibrary.initialize()` and `vp_lib_init()`.
- Pairing logs now print to the Xcode console with the `[Pairing]` prefix, so a rejected pairing shows its reason.

## 2026-10-20 fix: theater mode crashed with a Metal blit assertion
- Cause: the theater frame texture is `bgra8Unorm`, while RealityKit's screen `LowLevelTexture` is `bgra8Unorm_srgb`. A blit needs identical formats, so Metal API Validation asserted.
- Fix: the theater texture is created with `.pixelFormatView`, and `latestTheaterFrame()` returns a `bgra8Unorm_srgb` view of it. Colours are unchanged.
