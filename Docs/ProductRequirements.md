# Product Requirements

## 目标

做一个 Vision Pro 端 PS5 UVC Viewer，让用户通过 Developer Strap + HDMI 采集卡，在 Vision Pro 内以接近 4K 的画质玩 PS5。

## 第一阶段

只验证核心链路：

- 枚举 UVC 采集设备。
- 显示实时预览。
- 显示当前设备名称。
- 显示运行状态。
- 保持窗口比例适合 16:9。

暂不做：

- 录制。
- 串流。
- 云同步。
- 游戏库。
- 复杂空间影院效果。
- 120Hz/VRR。

## 第二阶段

在链路稳定后增加：

- 设备选择器。
- 分辨率/帧率显示。
- 音频输入选择。
- 延迟测试模式。
- 画面缩放：Fit / Fill / 1:1。
- 低延迟模式开关。
- 黑屏排障提示。

## 第三阶段

产品化：

- 沉浸式大屏。
- 曲面屏/影院空间。
- 手柄状态提示。
- 保存每个采集卡的偏好设置。
- App Store 权限和审核材料。

## 技术原则

- 第一优先级是低延迟。
- 第二优先级是稳定 4K60。
- 不在第一阶段做任何会明显增加处理延迟的图像后处理。
- 默认 SDR 4K60，HDR 单独验证。
