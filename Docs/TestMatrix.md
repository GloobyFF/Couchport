## visionOS 全应用手柄策略（真机待验证）

| 场景 | 预期结果 | 结果 |
| --- | --- | --- |
| 连接手柄后冷启动，停留首页 | 方向键、摇杆、确认键不操作应用 UI；注视和捏合仍可选主机 | 待验证 |
| 进入应用后再连接手柄 | 同样禁用手柄 UI 操作，无需先开启串流 | 待验证 |
| 2D 串流时注视视频、控制栏和菜单，操作手柄 | PS5 接收输入，应用按钮不被同时触发 | 待验证 |
| 打开设置、购买和 PSN 登录页 | 捏合、文本输入正常，手柄不导航应用页面 | 待验证 |
| 窗口进入沉浸，再返回窗口 | 场景切换正常，串流保持，手柄 UI 策略持续生效 | 待验证 |
| 停止串流返回首页，然后重连 | 首页仍不响应手柄 UI 操作，游戏输入在重连后恢复 | 待验证 |
| 应用退到后台、回到前台；手柄断开再连接 | 原系统快捷操作偏好在后台恢复，回到应用后重新请求禁用 | 待验证 |
| 隐藏双手开关开启、关闭 | 全沉浸隐藏双手，关闭恢复透视；主控制栏可用捏合操作 | 待验证 |

另行记录 Home、控制中心、系统窗口控件的响应。系统保留操作是否接受禁用请求由 visionOS 决定，不能以构建成功或模拟测试通过代替真机结论。
